## 🔄 Regra de Commit & Deploy Automático (OBRIGATÓRIO)
- **SEMPRE** que o agente fizer qualquer modificação, ajuste, adição de código, imagens ou conteúdo nos arquivos do projeto, **DEVE automaticamente executar o fluxo de publicação**:
  1. `git add -A`
  2. `git commit -m "<descrição clara das alterações>"`
  3. `git push origin main`
- Isso garante que a Vercel sempre receba o push e execute o deploy de produção imediatamente sem necessidade de o usuário pedir manualmente.
